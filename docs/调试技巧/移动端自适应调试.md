## 📐 常见自适应问题和解决方案

### 问题1：弹窗显示不全

**症状**：底部内容被截断，无法滚动

**原因**：
- `max-height` 设置过小
- 滚动容器没有设置 `overflow-y: auto`
- 父容器没有 `overflow: hidden`

**解决方案**：
```css
.category-picker {
  max-height: 80vh;
  overflow: hidden;
}

.cp-scroll {
  overflow-y: auto;
  max-height: calc(80vh - 120rpx);
}
```

---

### 问题2：内容溢出容器

**症状**：内容超出圆角边框

**解决方案**：
```css
.category-picker {
  overflow: hidden; /* 裁剪溢出内容 */
  border-radius: 24rpx 24rpx 0 0;
}
```

---

### 问题3：固定高度元素被压缩

**症状**：Tab栏或头部被压缩变形

**解决方案**：
```css
.cp-tabs {
  flex-shrink: 0; /* 防止被压缩 */
}
```

---

### 问题4：在不同设备上高度不一致

**症状**：iPhone和Android显示高度不同

**原因**：vh单位在不同设备上计算方式不同

**解决方案**：
```css
/* 方案A：使用百分比 */
.category-picker {
  max-height: 80%;
}

/* 方案B：使用calc动态计算 */
.category-picker {
  max-height: calc(100vh - env(safe-area-inset-bottom) - 40rpx);
}

/* 方案C：使用固定rpx（推荐uniapp） */
.category-picker {
  max-height: 1200rpx;
}
```

## 💡 实用调试技巧

### 技巧1：使用console输出容器高度

在组件的 `onMounted` 中添加：

```javascript
onMounted(() => {
  // 调试代码 - 查看实际视口高度
  const vh = uni.getSystemInfoSync().windowHeight;
  console.log('[调试] 视口高度:', vh, 'px');
  console.log('[调试] 80vh =', vh * 0.8, 'px');
  console.log('[调试] 设备信息:', uni.getSystemInfoSync());
});
```

### 技巧2：动态调整高度

临时添加按钮控制高度：

```vue
<view class="debug-controls">
  <button @tap="adjustHeight(70)">70vh</button>
  <button @tap="adjustHeight(80)">80vh</button>
  <button @tap="adjustHeight(90)">90vh</button>
</view>

<script>
const pickerHeight = ref('80vh');

function adjustHeight(value) {
  pickerHeight.value = `${value}vh`;
}
</script>

<style>
.category-picker {
  max-height: v-bind(pickerHeight);
}
</style>
```

## 📊 响应式设计最佳实践

### 1. 使用相对单位
```css
/* 好 */
.cp-scroll {
  max-height: calc(80vh - 120rpx);
}

/* 不好 */
.cp-scroll {
  max-height: 600px;
}
```

### 2. 设置最小/最大值
```css
.cp-scroll {
  min-height: 200rpx;
  max-height: calc(80vh - 120rpx);
}
```

### 3. 使用Flexbox自适应
```css
.category-picker {
  display: flex;
  flex-direction: column;
}

.cp-scroll {
  flex: 1; /* 自动填充剩余空间 */
  overflow-y: auto;
}
```

### 4. 考虑安全区域
```css
.category-picker {
  /* iOS刘海屏安全区域 */
  padding-bottom: env(safe-area-inset-bottom);
}
```

## 🚨 常见错误

### ❌ 错误1：忘记设置overflow
```css
/* 错误 */
.cp-scroll {
  max-height: 500rpx;
  /* 没有overflow-y: auto，无法滚动！ */
}

/* 正确 */
.cp-scroll {
  max-height: 500rpx;
  overflow-y: auto;
}
```

### ❌ 错误2：vh和rpx混用不当
```css
/* 错误 - calc中rpx可能不生效 */
max-height: calc(100vh - 120rpx);

/* 正确 - 转换为同一单位 */
max-height: calc(100vh - 60px); /* 120rpx ≈ 60px */
```

### ❌ 错误3：父容器没有设置高度
```css
/* 错误 - 父容器高度为auto，子元素的百分比高度失效 */
.parent {
  /* 没有设置height */
}
.child {
  height: 100%; /* 无效！ */
}

/* 正确 */
.parent {
  height: 100vh;
}
.child {
  height: 100%;
}
```
