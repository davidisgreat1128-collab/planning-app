## 临时解决方案（前端先行）

在后端调整前，采用以下临时方案：

1. **里程碑转任务**：在前端临时生成任务对象，不调用后端API
2. **象限属性**：默认所有里程碑为"重要不紧急"（蓝色，第二象限）
3. **任务存储**：在 planStore 中维护 `generatedTasks` 数组，视图层合并显示

**实现要点**：
```javascript
// planStore 新增字段
state: {
  plans: [],
  selectedPlanId: null,
  generatedTasks: []  // 从选中规划生成的任务
}

// 生成任务的逻辑
actions: {
  selectPlan(planId) {
    // ... 选中逻辑
    this.generateTasksFromPlan(plan);
  },

  generateTasksFromPlan(plan) {
    this.generatedTasks = plan.milestones.map(milestone => ({
      id: `plan_${plan.id}_milestone_${milestone.date}`,
      title: milestone.title,
      description: milestone.description,
      date: milestone.date.replace(/\//g, '-'),
      isUrgent: false,
      isImportant: true,  // 默认第二象限
      isAllDay: true,
      status: 'pending',
      fromPlan: true,
      planId: plan.id
    }));
  }
}
```
