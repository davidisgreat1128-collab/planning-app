## 📖 使用说明

### Claude 如何使用本文件

**1. 发现新的超标文件时**：
```markdown
步骤1：计算超标百分比
  超标% = (当前行数 - 800) / 800 * 100%

步骤2：确定优先级
  > 2000行 → P0
  1000-2000行 → P1
  800-1000行 → P2

步骤3：在"待处理"表格中新增一行
  填写：文件路径、行数、超标%、发现时间、状态"📋 已标记"

步骤4：在"最近提醒记录"中添加提醒记录

步骤5：向用户发出提醒
```

**2. 用户要求生成拆分方案时**：
```markdown
步骤1：创建评估报告和拆分方案文档

步骤2：更新本文件
  - 状态改为"🟡 评估中"
  - 在"拆分方案文档索引"中添加链接

步骤3：提交给用户审批
```

**3. 用户批准拆分后**：
```markdown
步骤1：状态改为"✅ 方案已批准"

步骤2：执行拆分

步骤3：拆分完成后，状态改为"✔️ 已完成"

步骤4：移动到"已处理"区域，更新统计数据
```

### 唐伯虎如何使用本文件

**查看当前超标文件状态**：
- 打开本文件，查看"待处理"表格
- 关注"统计数据"，了解整体健康度

**决策拆分优先级**：
- P0级文件建议优先处理（严重影响可维护性）
- 可以要求Claude生成某个文件的评估报告："生成 task-edit.vue 的拆分方案"

**审批拆分方案**：
- 查看"拆分方案文档索引"中的评估报告链接
- 审查后回复Claude："同意拆分 index.vue" 或 "暂不拆分"
