### 1.2 容器特性对比

| 容器类型 | 实现方式 | 数量 | 数据管理 | 排序方式 | 用途 |
|---------|---------|------|---------|---------|------|
| **全部** | 前端虚拟容器 | 1个（固定） | 聚合所有任务 | - | 查看所有任务 |
| **规划** | 后端表（planning_records） | N个（用户创建） | 后端数据库 + 前端Repository | 按创建时间倒序 | 复杂的分类，含目标/进度 |
| **分类** | 前端Repository（localStorage） | N个（用户创建） | 纯前端管理 | 按 sortOrder 手动排序 | 简单分类，快速分组 |
| **无分类** | 前端虚拟容器 | 1个（固定） | 过滤 planId=null && categoryId=null | - | 独立任务 |

### 1.3 任务分类判断逻辑

```javascript
/**
 * 判断任务所属容器
 * @param {Task} task - 任务对象
 * @returns {string} - 容器描述
 */
function getTaskContainer(task) {
  if (task.planId) {
    // 从 PlanningRepository 获取规划名称
    const planning = PlanningRepository.getById(task.planId);
    return `规划: ${planning?.title || '未知规划'}`;
  }

  if (task.categoryId) {
    // 从 CategoryRepository 获取分类名称
    const category = CategoryRepository.getById(task.categoryId);
    return `分类: ${category?.name || '未知分类'}`;
  }

  return '无分类';
}

// 示例调用
const task1 = { id: 1, title: '完成报告', planId: 'P001', categoryId: null };
getTaskContainer(task1); // => "规划: 人生规划"

const task2 = { id: 2, title: '看书', planId: null, categoryId: 'CAT002' };
getTaskContainer(task2); // => "分类: 学习"

const task3 = { id: 3, title: '买菜', planId: null, categoryId: null };
getTaskContainer(task3); // => "无分类"
```

### 3.2 Repository 设计模式

**核心特性**:
1. **离线优先** (Offline-First)：先写入内存和 localStorage，后台异步同步服务器
2. **内存缓存** (MemoryCache)：使用 Map 结构，O(1) 时间复杂度查找
3. **操作队列** (OperationQueue)：离线时记录操作，网络恢复后重放
4. **防抖同步** (Debounced Sync)：500ms 防抖，避免频繁网络请求
5. **指数退避** (Exponential Backoff)：重试间隔 1s → 2s → 4s → 8s → 16s
6. **软删除** (Soft Delete)：使用 deletedAt 字段，数据可恢复

**数据流**:
```
用户操作 → Repository.create/update/delete()
         ↓
    ┌────────────────────────────┐
    │  1. 立即写入 memoryCache    │ (同步，毫秒级)
    ├────────────────────────────┤
    │  2. 添加到 operationQueue   │ (同步)
    ├────────────────────────────┤
    │  3. 保存到 localStorage     │ (防抖 500ms)
    ├────────────────────────────┤
    │  4. 上传到服务器            │ (防抖 500ms + 指数退避)
    └────────────────────────────┘
         ↓
    UI 立即更新（响应式）
```

### 4.2 数据写入流程（Create/Update/Delete）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    用户操作（UI层）                                        │
│  例如: 创建任务、更新任务、删除任务                                        │
└────────────┬─────────────────────────────────────────────────────────────┘
             │
             ▼
    ┌────────────────────────┐
    │ Store层调用             │  例如: taskStore.addTask(data)
    │ (Pinia)                │
    └───┬────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────────────────────────┐
│ Repository层处理                                                          │
│ ─────────────────────────────────────────────────────────────────────────│
│                                                                           │
│  步骤1: 立即写入内存（同步，0ms）                                          │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │ memoryCache.set(id, newData)                                    │    │
│  │ UI 立即响应（Vue响应式系统触发更新）                              │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                           │
│  步骤2: 添加到操作队列（同步，1ms）                                        │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │ operationQueue.push({ type: 'create', entityId, data })         │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                           │
│  步骤3: 防抖写入 localStorage（异步，500ms防抖）                          │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │ setTimeout(() => {                                              │    │
│  │   localStorage.setItem('key', JSON.stringify(data))             │    │
│  │ }, 500)                                                          │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                           │
│  步骤4: 防抖同步服务器（异步，500ms防抖 + 指数退避重试）                    │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │ setTimeout(() => {                                              │    │
│  │   try {                                                          │    │
│  │     await api.createTask(data)  // HTTP POST /api/v1/tasks      │    │
│  │     operationQueue.shift()      // 成功后移除队列                 │    │
│  │   } catch (err) {                                                │    │
│  │     retryCount++                                                 │    │
│  │     // 指数退避: 1s → 2s → 4s → 8s → 16s                         │    │
│  │     setTimeout(retry, Math.pow(2, retryCount) * 1000)           │    │
│  │   }                                                              │    │
│  │ }, 500)                                                          │    │
│  └─────────────────────────────────────────────────────────────────┘    │
└───────────────────────────────────────────────────────────────────────────┘
             │
             ▼
    ┌────────────────────────┐
    │ 后端处理                │
    │ Route → Controller      │
    │       → Service         │
    │       → Sequelize ORM   │
    │       → MySQL           │
    └───┬────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────────────────────────┐
│ 响应返回                                                                  │
│ ─────────────────────────────────────────────────────────────────────────│
│  - 成功: 更新 memoryCache（替换临时ID为服务器ID）                         │
│  - 失败: 保留在 operationQueue，下次重试                                  │
└───────────────────────────────────────────────────────────────────────────┘
```

### 4.3 数据读取流程（Query）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    UI组件需要数据                                          │
│  例如: 日历页面需要某日期的任务                                            │
└────────────┬─────────────────────────────────────────────────────────────┘
             │
             ▼
    ┌────────────────────────┐
    │ Store computed属性      │  例如: taskStore.tasks（响应式）
    │ (Pinia)                │
    └───┬────────────────────┘
        │
        ▼
┌───────────────────────────────────────────────────────────────────────────┐
│ Repository查询                                                            │
│ ─────────────────────────────────────────────────────────────────────────│
│                                                                           │
│  直接从内存缓存读取（O(1) 时间复杂度）                                     │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │ getByDate(date) {                                               │    │
│  │   return Array.from(this.memoryCache.values())                  │    │
│  │     .filter(task => !task.deletedAt)  // 过滤软删除              │    │
│  │     .filter(task => task.taskDate === date)                     │    │
│  │ }                                                                │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                           │
│  ⭐ 无需网络请求，毫秒级响应                                               │
└───────────────────────────────────────────────────────────────────────────┘
             │
             ▼
    ┌────────────────────────┐
    │ 返回给UI组件            │
    │ Vue响应式渲染          │
    └────────────────────────┘
```

## 5. 三层架构详解

### 5.1 前端三层架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         Component 层 (表现层)                             │
│                      Vue组件 (.vue 文件)                                 │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 渲染UI界面                                                            │
│  - 响应用户交互                                                          │
│  - 调用 Store 方法                                                       │
│  - 禁止直接调用 Repository 或 API                                        │
│                                                                          │
│  示例: pages/calendar/index.vue                                         │
│  ```javascript                                                          │
│  import { useTaskStore } from '@/store/task'                            │
│  const taskStore = useTaskStore()                                       │
│  taskStore.fetchTasksByDate('2026-03-05')  // 调用Store方法              │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         Store 层 (状态管理层)                             │
│                      Pinia Store                                         │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 管理全局状态（响应式）                                                 │
│  - 提供计算属性（computed）                                              │
│  - 调用 Repository 方法                                                  │
│  - 禁止直接调用 API                                                      │
│                                                                          │
│  示例: store/task.js                                                    │
│  ```javascript                                                          │
│  import TaskRepository from '@/repositories/TaskRepository'             │
│                                                                          │
│  export const useTaskStore = defineStore('task', () => {                │
│    const tasks = ref([])  // 响应式状态                                 │
│                                                                          │
│    async function fetchTasksByDate(date) {                              │
│      loading.value = true                                               │
│      tasks.value = TaskRepository.getByDate(date)  // 调用Repository    │
│      loading.value = false                                              │
│    }                                                                     │
│                                                                          │
│    return { tasks, fetchTasksByDate }                                   │
│  })                                                                      │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                       Repository 层 (数据访问层)                          │
│                  离线优先数据管理                                         │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 管理内存缓存 (memoryCache)                                            │
│  - 持久化到 localStorage                                                 │
│  - 管理操作队列 (operationQueue)                                         │
│  - 调用后端 API 同步数据                                                 │
│  - 提供 CRUD 接口                                                        │
│                                                                          │
│  示例: repositories/TaskRepository.js                                   │
│  ```javascript                                                          │
│  import { createTask as createTaskApi } from '@/api/task'               │
│                                                                          │
│  class TaskRepository {                                                 │
│    constructor() {                                                      │
│      this.memoryCache = new Map()                                       │
│      this.operationQueue = []                                           │
│    }                                                                     │
│                                                                          │
│    getByDate(date) {                                                    │
│      return Array.from(this.memoryCache.values())                       │
│        .filter(task => task.taskDate === date)                          │
│    }                                                                     │
│                                                                          │
│    async create(data) {                                                 │
│      const task = { id: this._generateId(), ...data }                   │
│      this.memoryCache.set(task.id, task)  // 立即写入内存                │
│      this._addToQueue({ type: 'create', data: task })                   │
│      this._debouncedSync()  // 异步同步服务器                            │
│      return task                                                         │
│    }                                                                     │
│                                                                          │
│    async sync() {                                                       │
│      await this._uploadQueue()  // 上传操作队列                          │
│    }                                                                     │
│                                                                          │
│    async _uploadQueue() {                                               │
│      for (const op of this.operationQueue) {                            │
│        await createTaskApi(op.data)  // 调用API层                        │
│      }                                                                   │
│    }                                                                     │
│  }                                                                       │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         API 层 (网络请求层)                               │
│                   封装 HTTP 请求                                          │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 封装 HTTP 请求（axios）                                               │
│  - 统一处理请求/响应拦截器                                                │
│  - 错误处理                                                              │
│  - 禁止包含业务逻辑                                                       │
│                                                                          │
│  示例: api/task.js                                                      │
│  ```javascript                                                          │
│  import request from '@/utils/request'  // axios实例                     │
│                                                                          │
│  export function createTask(data) {                                     │
│    return request({                                                     │
│      url: '/api/v1/tasks',                                              │
│      method: 'POST',                                                    │
│      data                                                               │
│    })                                                                    │
│  }                                                                       │
│                                                                          │
│  export function getTasks(params) {                                     │
│    return request({                                                     │
│      url: '/api/v1/tasks',                                              │
│      method: 'GET',                                                     │
│      params                                                             │
│    })                                                                    │
│  }                                                                       │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │ HTTP Request
             ▼
        ┌─────────────┐
        │  后端 API    │
        └─────────────┘
```

### 5.2 后端三层架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         Route 层 (路由层)                                 │
│                   注册路由 + 中间件                                        │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 定义路由规则                                                          │
│  - 引入中间件（认证/验证/日志）                                           │
│  - 定义 Joi 验证 Schema                                                  │
│  - 调用 Controller 方法                                                  │
│  - 禁止包含业务逻辑                                                       │
│                                                                          │
│  示例: routes/task.js                                                   │
│  ```javascript                                                          │
│  const express = require('express')                                     │
│  const router = express.Router()                                        │
│  const { authenticate } = require('../middleware/auth')                 │
│  const { validate } = require('../middleware/validator')                │
│  const taskController = require('../controllers/taskController')        │
│  const Joi = require('joi')                                             │
│                                                                          │
│  // 创建任务 Schema                                                      │
│  const createTaskSchema = Joi.object({                                  │
│    title: Joi.string().required(),                                      │
│    taskDate: Joi.date().iso()                                           │
│  })                                                                      │
│                                                                          │
│  router.post('/tasks',                                                  │
│    authenticate,               // 认证中间件                            │
│    validate(createTaskSchema), // 验证中间件                            │
│    taskController.createTask   // 控制器方法                            │
│  )                                                                       │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                       Controller 层 (控制器层)                            │
│                   处理请求/响应                                           │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 解析请求参数 (req.body / req.params / req.query)                     │
│  - 调用 Service 层方法                                                   │
│  - 格式化响应（使用 success/error 统一格式）                             │
│  - 异常处理（try-catch）                                                 │
│  - 禁止直接操作 Model/数据库                                             │
│                                                                          │
│  示例: controllers/taskController.js                                    │
│  ```javascript                                                          │
│  const taskService = require('../services/taskService')                 │
│  const { success, error } = require('../utils/response')                │
│                                                                          │
│  async function createTask(req, res) {                                  │
│    try {                                                                │
│      const userId = req.user.id  // 从认证中间件获取                     │

│                                                                          │
│      const task = await taskService.createTask(userId, data)            │

│      res.status(500).json(error('任务创建失败', 500))                    │
│    }                                                                     │
│  }                                                                       │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                       Service 层 (业务逻辑层)                             │
│                   核心业务逻辑                                            │
│  ─────────────────────────────────────────────────────────────────────  │
│  职责:                                                                   │
│  - 实现核心业务逻辑                                                       │
│  - 调用 Model 层（Sequelize）                                            │
│  - 数据转换/聚合                                                         │
│  - 复杂查询/事务处理                                                      │
│  - 可以调用其他 Service                                                  │
│                                                                          │
│  示例: services/taskService.js                                          │

│                                                                          │

│  }                                                                       │
│  ```                                                                     │
└────────────┬────────────────────────────────────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                         Model 层 (数据模型层)                             │

│  职责:                                                                   │

## 📌 重要说明

### Category 混合模式（待实现）

当前 Category 是**纯前端管理**（localStorage），数据仅存储在客户端。

**混合模式**（前端优先 + 后台备份同步）计划在后续版本实现：

**实现方案**:
1. **保持前端性能**: Category 仍然从 localStorage 读取（毫秒级响应）
2. **后台备份**: 定期同步到后端（防止数据丢失）
3. **跨设备恢复**: 换设备时从后端拉取分类数据
4. **同步策略**: 类似 PlanningRepository 的 sync() 机制

**需要实现**:
- [ ] 后端创建 `categories` 表（字段与前端一致）
- [ ] 后端实现 Category API（CRUD）
- [ ] CategoryRepository 实现 `sync()` 方法
- [ ] 应用启动时从服务器恢复分类数据

### Planning 排序规则

PlanningRepository **不支持手动排序**，始终按创建时间倒序排列（最新的在前）。

**设计理由**:
- 规划数量通常较少（7大类型）
- 按时间排序符合"最新规划优先"的业务逻辑
- 简化实现，避免增加 `sortOrder` 字段和 `reorder()` 方法

如未来需要手动排序，可参考 CategoryRepository 的实现添加。
