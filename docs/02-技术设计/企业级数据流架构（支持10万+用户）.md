## 3. DTO层设计

### 3.1 DTO 是什么？

**DTO**（Data Transfer Object）= 数据传输对象

**作用**：
1. **统一数据格式**：前端、后端、缓存的数据格式不同，DTO 统一转换
2. **屏蔽差异**：前端用 `camelCase`，后端用 `snake_case`，DTO 自动转换
3. **类型安全**：未来迁移 TypeScript 时，DTO 提供类型定义

### 3.2 CategoryDTO 实现

```javascript
/**
 * 分类数据传输对象
 */
class CategoryDTO {
  constructor(data) {
    this.id = data.id || null
    this.name = data.name || ''
    this.color = data.color || '#000000'
    this.sortOrder = data.sortOrder || 0
    this.version = data.version || 1
    this.createdAt = data.createdAt || Date.now()
    this.updatedAt = data.updatedAt || Date.now()
    this.deletedAt = data.deletedAt || null
  }

  /**
   * 从客户端表单创建 DTO
   * @param {object} formData - 前端表单数据
   * @returns {CategoryDTO}
   */
  static fromClient(formData) {
    return new CategoryDTO({
      name: formData.name?.trim(),  // 去除首尾空格
      color: formData.color || '#000000',
      sortOrder: formData.sortOrder || 0
    })
  }

  /**
   * 从服务器响应创建 DTO
   * @param {object} serverData - 后端 API 响应
   * @returns {CategoryDTO}
   */
  static fromServer(serverData) {
    return new CategoryDTO({
      id: serverData.id,
      name: serverData.name,
      color: serverData.color,
      sortOrder: serverData.sort_order,  // ← snake_case → camelCase
      version: serverData.version,
      createdAt: serverData.created_at,
      updatedAt: serverData.updated_at,
      deletedAt: serverData.deleted_at
    })
  }

  /**
   * 从 localStorage 缓存创建 DTO
   * @param {object} cachedData - localStorage 数据
   * @returns {CategoryDTO}
   */
  static fromCache(cachedData) {
    return new CategoryDTO(cachedData)
  }

  /**
   * 转换为服务器格式（用于 API 请求）
   * @returns {object}
   */
  toServer() {
    return {
      id: this.id,
      name: this.name,
      color: this.color,
      sort_order: this.sortOrder,  // ← camelCase → snake_case
      version: this.version,
      created_at: this.createdAt,
      updated_at: this.updatedAt,
      deleted_at: this.deletedAt
    }
  }

  /**
   * 转换为客户端格式（用于 Component 展示）
   * @returns {object}
   */
  toClient() {
    return {
      id: this.id,
      name: this.name,
      color: this.color,
      sortOrder: this.sortOrder,
      version: this.version,
      createdAt: this.createdAt,
      updatedAt: this.updatedAt,
      deletedAt: this.deletedAt,
      // 额外字段（仅客户端使用）
      isDeleted: !!this.deletedAt
    }
  }

  /**
   * 转换为缓存格式（用于 localStorage）
   * @returns {object}
   */
  toCache() {
    return {
      id: this.id,
      name: this.name,
      color: this.color,
      sortOrder: this.sortOrder,
      version: this.version,
      createdAt: this.createdAt,
      updatedAt: this.updatedAt,
      deletedAt: this.deletedAt
    }
  }
}

export default CategoryDTO
```

### 3.3 使用示例


### 3.4 DTO 层的价值

| 场景 | 无 DTO | 有 DTO |
|------|--------|--------|
| 前后端字段不一致 | 手动转换 `data.sort_order` → `data.sortOrder`，容易遗漏 | 自动转换 `CategoryDTO.fromServer()` |
| 数据验证 | 在多处重复验证 | 统一在 DTO 构造函数验证 |
| 类型错误 | 运行时才发现 `sortOrder` 是字符串 | DTO 构造时强制转换 `Number(sortOrder)` |
| 迁移 TypeScript | 需要改动所有文件 | 只需给 DTO 加类型定义 |

## 4. Validator层设计

### 4.1 Validator 是什么？

**Validator** = 数据验证器

**作用**：
1. **字段验证**：检查必填字段、类型、长度、格式
2. **业务规则验证**：检查业务逻辑（如分类名称不能重复）
3. **跨字段验证**：检查多个字段的关联关系

### 4.2 CategoryValidator 实现

```javascript
/**
 * 分类验证器
 */
class CategoryValidator {
  /**
   * 验证分类 DTO
   * @param {CategoryDTO} dto
   * @param {Array<CategoryDTO>} existingCategories - 现有分类列表
   * @returns {{ valid: boolean, errors: Array<string> }}
   */
  static validate(dto, existingCategories = []) {
    const errors = []

    // 1. 字段验证
    errors.push(...this._validateFields(dto))

    // 2. 业务规则验证
    errors.push(...this._validateBusinessRules(dto, existingCategories))

    // 3. 跨字段验证
    errors.push(...this._validateCrossFields(dto))

    return {
      valid: errors.length === 0,
      errors
    }
  }

  /**
   * 字段验证
   */
  static _validateFields(dto) {
    const errors = []

    // name 字段
    if (!dto.name || dto.name.trim().length === 0) {
      errors.push('分类名称不能为空')
    } else if (dto.name.length > 20) {
      errors.push('分类名称不能超过20个字符')
    } else if (/[<>]/.test(dto.name)) {
      errors.push('分类名称不能包含特殊字符 < >')
    }

    // color 字段
    if (!dto.color) {
      errors.push('颜色不能为空')
    } else if (!/^#[0-9A-F]{6}$/i.test(dto.color)) {
      errors.push('颜色格式不正确（应为 #RRGGBB）')
    }

    // sortOrder 字段
    if (dto.sortOrder < 0) {
      errors.push('排序值不能为负数')
    } else if (!Number.isInteger(dto.sortOrder)) {
      errors.push('排序值必须为整数')
    }

    return errors
  }

  /**
   * 业务规则验证
   */
  static _validateBusinessRules(dto, existingCategories) {
    const errors = []

    // 规则1: 分类名称不能重复
    const duplicate = existingCategories.find(
      cat => cat.name === dto.name && cat.id !== dto.id
    )
    if (duplicate) {
      errors.push(`分类"${dto.name}"已存在，不能重复创建`)
    }

    // 规则2: 分类数量不能超过 50 个
    if (existingCategories.length >= 50 && !dto.id) {
      errors.push('分类数量已达上限（50个），无法创建新分类')
    }

    // 规则3: 删除的分类不能编辑
    if (dto.id && dto.deletedAt) {
      errors.push('已删除的分类无法编辑')
    }

    return errors
  }

  /**
   * 跨字段验证
   */
  static _validateCrossFields(dto) {
    const errors = []

    // 规则1: 如果是新建分类，version 必须为 1
    if (!dto.id && dto.version !== 1) {
      errors.push('新建分类的版本号必须为1')
    }

    // 规则2: createdAt 不能晚于 updatedAt
    if (dto.createdAt > dto.updatedAt) {
      errors.push('创建时间不能晚于更新时间')
    }

    return errors
  }

  /**
   * 快速验证（只检查必填字段）
   */
  static quickValidate(dto) {
    return !!(dto.name && dto.name.trim().length > 0 && dto.color)
  }
}

export default CategoryValidator
```

### 4.3 使用示例


## 5. RepositoryFactory设计

### 5.1 RepositoryFactory 是什么？

**RepositoryFactory** = 存储工厂

**作用**：
根据设备性能、网络状况、数据量，**自动选择最佳存储方式**

### 5.2 存储策略

```javascript
/**
 * 存储策略枚举
 */
const StorageStrategy = {
  MEMORY: 'memory',            // 纯内存（最快，但刷新丢失）
  LOCAL_STORAGE: 'localStorage', // localStorage（中速，持久化）
  INDEXED_DB: 'indexedDB',      // IndexedDB（慢，大容量）
  REMOTE: 'remote'              // 仅服务器（无缓存）
}

/**
 * 选择策略的判断逻辑
 */
class RepositoryFactory {
  /**
   * 创建最佳 Repository 实例
   * @param {string} entityType - 实体类型（'category' / 'task' / 'planning'）
   * @returns {BaseRepository}
   */
  static create(entityType) {
    const strategy = this._selectStrategy()

    switch (strategy) {
      case StorageStrategy.MEMORY:
        return new MemoryRepository(entityType)

      case StorageStrategy.LOCAL_STORAGE:
        return new LocalStorageRepository(entityType)

      case StorageStrategy.INDEXED_DB:
        return new IndexedDBRepository(entityType)

      case StorageStrategy.REMOTE:
        return new RemoteRepository(entityType)

      default:
        return new LocalStorageRepository(entityType)  // 默认策略
    }
  }

  /**
   * 选择最佳存储策略
   */
  static _selectStrategy() {
    // 判断1: 检查内存情况
    const memoryInfo = this._getMemoryInfo()
    if (memoryInfo.available < 50) {  // 可用内存 < 50MB
      console.warn('内存不足，使用 LocalStorage')
      return StorageStrategy.LOCAL_STORAGE
    }

    // 判断2: 检查数据量
    const dataSize = this._estimateDataSize()
    if (dataSize > 5 * 1024 * 1024) {  // 数据量 > 5MB
      console.warn('数据量过大，使用 IndexedDB')
      return StorageStrategy.INDEXED_DB
    }

    // 判断3: 检查网络状况
    const online = navigator.onLine
    if (!online) {
      console.log('离线模式，使用 Memory + LocalStorage')
      return StorageStrategy.MEMORY
    }

    // 判断4: 检查设备性能
    const devicePerformance = this._getDevicePerformance()
    if (devicePerformance === 'low') {
      console.warn('低性能设备，使用 RemoteRepository（减少本地计算）')
      return StorageStrategy.REMOTE
    }

    // 默认：Memory（最快）
    return StorageStrategy.MEMORY
  }

  /**
   * 获取内存信息
   */
  static _getMemoryInfo() {
    // Chrome / Edge
    if (performance.memory) {
      const { usedJSHeapSize, jsHeapSizeLimit } = performance.memory
      return {
        used: usedJSHeapSize / 1024 / 1024,  // MB
        total: jsHeapSizeLimit / 1024 / 1024,
        available: (jsHeapSizeLimit - usedJSHeapSize) / 1024 / 1024
      }
    }

    // 其他浏览器（无法检测，返回默认值）
    return { available: 200 }  // 假设 200MB 可用
  }

  /**
   * 估算数据大小
   */
  static _estimateDataSize() {
    const keys = ['planning_app_categories', 'planning_app_tasks', 'planning_app_plannings']
    let totalSize = 0

    keys.forEach(key => {
      const data = localStorage.getItem(key)
      if (data) {
        totalSize += data.length * 2  // 每个字符约 2 字节
      }
    })

    return totalSize
  }

  /**
   * 获取设备性能
   */
  static _getDevicePerformance() {
    const cores = navigator.hardwareConcurrency || 2
    const memory = navigator.deviceMemory || 4  // GB

    if (cores >= 8 && memory >= 8) {
      return 'high'
    } else if (cores >= 4 && memory >= 4) {
      return 'medium'
    } else {
      return 'low'
    }
  }
}

export default RepositoryFactory
```

## 6. ErrorRecovery设计

### 6.1 ErrorRecovery 是什么？

**ErrorRecovery** = 错误恢复器

**作用**：
当服务器异常、网络超时、数据损坏时，**自动降级**，确保用户仍可操作

### 6.2 容错策略

```javascript
/**
 * 错误恢复器
 */
class ErrorRecovery {
  /**
   * 处理 Repository 操作错误
   * @param {Error} error - 错误对象
   * @param {string} operation - 操作类型（'create' / 'update' / 'delete' / 'sync'）
   * @param {object} context - 上下文信息
   * @returns {object} 恢复策略
   */
  static handle(error, operation, context) {
    // 1. 网络错误
    if (this._isNetworkError(error)) {
      return this._handleNetworkError(operation, context)
    }

    // 2. 服务器错误（500/502/503）
    if (this._isServerError(error)) {
      return this._handleServerError(operation, context)
    }

    // 3. 权限错误（401/403）
    if (this._isAuthError(error)) {
      return this._handleAuthError(operation, context)
    }

    // 4. 数据损坏
    if (this._isDataCorruption(error)) {
      return this._handleDataCorruption(operation, context)
    }

    // 5. 未知错误
    return this._handleUnknownError(error, operation, context)
  }

  /**
   * 处理网络错误
   */
  static _handleNetworkError(operation, context) {
    console.warn('网络错误，启用离线模式')

    return {
      strategy: 'offline',
      action: () => {
        // 添加到离线队列
        context.repository.operationQueue.push({
          type: operation,
          data: context.data,
          timestamp: Date.now(),
          status: 'pending'
        })

        // 使用本地缓存
        if (operation === 'create') {
          const localId = `local_${Date.now()}`
          context.repository.memoryCache.set(localId, context.data)
        }

        // 提示用户
        uni.showToast({
          title: '当前离线，数据已保存到本地',
          icon: 'none'
        })
      },
      retryable: true,  // 可重试
      retryDelay: 5000  // 5秒后重试
    }
  }

  /**
   * 处理服务器错误
   */
  static _handleServerError(operation, context) {
    console.error('服务器异常，降级到本地模式')

    return {
      strategy: 'fallback',
      action: () => {
        // 降级策略：仅使用本地缓存
        context.repository.isSyncing = false

        // 提示用户
        uni.showModal({
          title: '服务器维护中',
          content: '当前使用离线模式，数据将在服务器恢复后自动同步',
          showCancel: false
        })
      },
      retryable: true,
      retryDelay: 60000  // 1分钟后重试
    }
  }

  /**
   * 处理权限错误
   */
  static _handleAuthError(operation, context) {
    console.error('权限错误，需要重新登录')

    return {
      strategy: 'reauth',
      action: () => {
        // 清除 Token
        uni.removeStorageSync('token')

        // 跳转登录页
        uni.navigateTo({ url: '/pages/login/login' })

        uni.showToast({
          title: '登录已过期，请重新登录',
          icon: 'none'
        })
      },
      retryable: false  // 不可自动重试
    }
  }

  /**
   * 处理数据损坏
   */
  static _handleDataCorruption(operation, context) {
    console.error('数据损坏，尝试自动修复')

    return {
      strategy: 'repair',
      action: async () => {
        try {
          // 尝试修复：重新从服务器加载
          const serverData = await context.repository.api.getAll()

          // 覆盖本地缓存
          context.repository.memoryCache.clear()
          serverData.forEach(item => {
            context.repository.memoryCache.set(item.id, item)
          })

          // 重新写入 localStorage
          context.repository._saveToLocalStorage()

          uni.showToast({
            title: '数据已自动修复',
            icon: 'success'
          })
        } catch (err) {
          // 修复失败，提示用户
          uni.showModal({
            title: '数据损坏',
            content: '无法自动修复，请清除缓存后重新登录',
            confirmText: '清除缓存',
            success: (res) => {
              if (res.confirm) {
                localStorage.clear()
                uni.reLaunch({ url: '/pages/login/login' })
              }
            }
          })
        }
      },
      retryable: false
    }
  }

  /**
   * 判断是否为网络错误
   */
  static _isNetworkError(error) {
    return (
      error.message === 'Network Error' ||
      error.code === 'ECONNABORTED' ||
      error.code === 'ERR_NETWORK'
    )
  }

  /**
   * 判断是否为服务器错误
   */
  static _isServerError(error) {
    const status = error.response?.status
    return status >= 500 && status < 600
  }

  /**
   * 判断是否为权限错误
   */
  static _isAuthError(error) {
    const status = error.response?.status
    return status === 401 || status === 403
  }

  /**
   * 判断是否为数据损坏
   */
  static _isDataCorruption(error) {
    return (
      error.message?.includes('JSON.parse') ||
      error.message?.includes('Unexpected token')
    )
  }
}

export default ErrorRecovery
```

## 7. PerformanceMonitor设计

### 7.1 PerformanceMonitor 是什么？

**PerformanceMonitor** = 性能监控器

**作用**：
1. **记录操作耗时**：每个 Repository 操作的耗时
2. **分析缓存命中率**：从缓存读取 vs 从服务器读取
3. **监控同步成功率**：成功 / 失败 / 重试次数
4. **自动优化建议**：发现性能瓶颈，提供优化建议

### 7.2 PerformanceMonitor 实现

```javascript
/**
 * 性能监控器
 */
class PerformanceMonitor {
  constructor() {
    this.metrics = {
      operations: [],      // 操作记录
      cacheHits: 0,        // 缓存命中次数
      cacheMisses: 0,      // 缓存未命中次数
      syncSuccesses: 0,    // 同步成功次数
      syncFailures: 0      // 同步失败次数
    }
  }

  /**
   * 跟踪操作耗时
   * @param {string} operation - 操作名称（'create' / 'update' / 'sync'）
   * @param {Function} fn - 要执行的函数
   * @returns {Promise}
   */
  async track(operation, fn) {
    const startTime = performance.now()

    try {
      const result = await fn()
      const duration = performance.now() - startTime

      // 记录成功操作
      this.metrics.operations.push({
        operation,
        duration,
        success: true,
        timestamp: Date.now()
      })

      // 检查是否异常慢
      if (duration > 1000) {
        console.warn(`操作 ${operation} 耗时 ${duration.toFixed(0)}ms，超过阈值`)
        this._triggerSlowOperationAlert(operation, duration)
      }

      return result
    } catch (error) {
      const duration = performance.now() - startTime

      // 记录失败操作
      this.metrics.operations.push({
        operation,
        duration,
        success: false,
        error: error.message,
        timestamp: Date.now()
      })

      throw error
    }
  }

  /**
   * 记录缓存命中
   */
  recordCacheHit() {
    this.metrics.cacheHits++
  }

  /**
   * 记录缓存未命中
   */
  recordCacheMiss() {
    this.metrics.cacheMisses++
  }

  /**
   * 记录同步成功
   */
  recordSyncSuccess() {
    this.metrics.syncSuccesses++
  }

  /**
   * 记录同步失败
   */
  recordSyncFailure() {
    this.metrics.syncFailures++
  }

  /**
   * 生成性能报告
   */
  generateReport() {
    const ops = this.metrics.operations

    // 计算平均耗时
    const avgDuration = ops.reduce((sum, op) => sum + op.duration, 0) / ops.length

    // 计算缓存命中率
    const cacheHitRate =
      this.metrics.cacheHits / (this.metrics.cacheHits + this.metrics.cacheMisses) * 100

    // 计算同步成功率
    const syncSuccessRate =
      this.metrics.syncSuccesses /
      (this.metrics.syncSuccesses + this.metrics.syncFailures) * 100

    // 找出最慢的操作
    const slowestOps = ops
      .filter(op => op.success)
      .sort((a, b) => b.duration - a.duration)
      .slice(0, 5)

    return {
      summary: {
        totalOperations: ops.length,
        avgDuration: avgDuration.toFixed(2) + 'ms',
        cacheHitRate: cacheHitRate.toFixed(2) + '%',
        syncSuccessRate: syncSuccessRate.toFixed(2) + '%'
      },
      slowestOperations: slowestOps.map(op => ({
        operation: op.operation,
        duration: op.duration.toFixed(2) + 'ms',
        timestamp: new Date(op.timestamp).toLocaleString()
      })),
      recommendations: this._generateRecommendations()
    }
  }

  /**
   * 生成优化建议
   */
  _generateRecommendations() {
    const recommendations = []

    // 建议1: 缓存命中率低
    const cacheHitRate =
      this.metrics.cacheHits / (this.metrics.cacheHits + this.metrics.cacheMisses)
    if (cacheHitRate < 0.7) {
      recommendations.push({
        level: 'warning',
        message: `缓存命中率仅 ${(cacheHitRate * 100).toFixed(0)}%，建议增加缓存时间`
      })
    }

    // 建议2: 同步成功率低
    const syncSuccessRate =
      this.metrics.syncSuccesses /
      (this.metrics.syncSuccesses + this.metrics.syncFailures)
    if (syncSuccessRate < 0.9) {
      recommendations.push({
        level: 'error',
        message: `同步成功率仅 ${(syncSuccessRate * 100).toFixed(0)}%，网络或服务器可能存在问题`
      })
    }

    // 建议3: 平均耗时过高
    const avgDuration =
      this.metrics.operations.reduce((sum, op) => sum + op.duration, 0) /
      this.metrics.operations.length
    if (avgDuration > 500) {
      recommendations.push({
        level: 'warning',
        message: `平均操作耗时 ${avgDuration.toFixed(0)}ms，建议检查数据量或优化算法`
      })
    }

    return recommendations
  }

  /**
   * 触发慢操作告警
   */
  _triggerSlowOperationAlert(operation, duration) {
    // 可以发送到监控平台（如 Sentry）
    console.error(`[PerformanceMonitor] 慢操作告警`, {
      operation,
      duration: duration.toFixed(2) + 'ms',
      threshold: '1000ms'
    })
  }
}

// 单例
export default new PerformanceMonitor()
```
