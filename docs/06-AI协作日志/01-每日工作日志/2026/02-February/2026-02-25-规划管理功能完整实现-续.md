#### 3. 规划任务生成系统

**核心逻辑**: 当用户选中一个规划时，将该规划的所有里程碑自动转换为任务对象

**生成规则**（临时方案）:
```javascript
// 每个里程碑转换为一个任务
task = {
  id: `plan_${planId}_milestone_${index}`,

  // 基本信息
  title: milestone.title,
  description: milestone.description,

  // 日期
  date: '2026-03-05',  // 从 YYYY/MM/DD 转换为 YYYY-MM-DD
  isAllDay: true,

  // 四象限属性（默认：重要不紧急 - 蓝色）
  isUrgent: false,
  isImportant: true,

  // 状态
  status: 'pending',  // 或 'completed'

  // 来源标记
  fromPlan: true,
  planId: plan.id,
  milestoneIndex: 0,

  // 其他
  categoryId: null,
  notes: '来自规划：考研上岸\n第10天'
}
```

**为什么默认是"重要不紧急"（蓝色）**:
- 规划的里程碑通常是长期目标的阶段性成果
- 符合时间管理第二象限的定义
- 用户可以在日历中手动调整象限属性（后续功能）

## 🔧 技术实现细节

### 1. 任务数据结构兼容

**后端任务字段**:
```javascript
{
  id: 1,
  title: '...',
  taskDate: '2026-02-25',  // 日期字段名
  isUrgent: true,
  isImportant: true,
  status: 'pending',
  categoryId: 'cat123'
}
```

**规划任务字段**:
```javascript
{
  id: 'plan_123_milestone_0',
  title: '...',
  date: '2026-03-05',      // 日期字段名不同
  isUrgent: false,
  isImportant: true,
  status: 'pending',
  fromPlan: true,          // 特殊标记
  planId: '123',
  milestoneIndex: 0
}
```

**兼容处理**:
```javascript
// 日期获取时兼容两种字段名
const taskDate = t.date || t.taskDate || '';
```

### 2. 日期格式转换

**规划中的日期格式**: `YYYY/MM/DD`（例如 `2026/03/05`）
**任务中的日期格式**: `YYYY-MM-DD`（例如 `2026-03-05`）

**转换代码**:
```javascript
// 生成任务时转换
const dateStr = milestone.date.replace(/\//g, '-');
```

### 3. 性能优化

**优化点1**: 只生成选中日期的任务
```javascript
const mergedTasks = computed(() => {
  const planTasks = planStore.getTasksByDate(selectedDate.value);
  // 而不是 planStore.allGeneratedTasks
});
```

**优化点2**: 使用计算属性缓存
```javascript
// getTasksByDate 在 planStore 中是 getter
getTasksByDate: (state) => (dateStr) => {
  return state.generatedTasks.filter(t => t.date === dateStr);
}
```

## 🐛 已知问题

### 问题1：规划任务不可编辑
- **现象**: 点击规划生成的任务无法编辑
- **原因**: 任务ID格式为 `plan_xxx_milestone_0`，后端无法识别
- **临时方案**: 规划任务仅展示，不支持编辑
- **解决时间**: 待后端集成时处理

### 问题2：完成任务不同步
- **现象**: 在日历中完成规划任务，里程碑统计不更新
- **原因**: 未实现完成事件监听
- **临时方案**: 需要手动在规划详情中标记里程碑完成
- **解决时间**: 下一个迭代

### 问题3：跨天任务显示
- **现象**: 所有里程碑都是全天任务
- **原因**: 里程碑数据结构无时间字段
- **影响**: 无法在时间轴的具体时间段显示
- **解决时间**: 待产品确认需求
