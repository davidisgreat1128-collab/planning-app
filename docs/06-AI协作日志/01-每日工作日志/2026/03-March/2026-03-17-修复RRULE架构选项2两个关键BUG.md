## 🐛 BUG-008：新任务继承UNTIL导致RRULE解析失败

### 问题现象

**前端日志**：
```javascript
task.js:257 [TaskStore] 加载任务失败
Error: RRULE解析失败: Invalid date passed to DateWithZone
```

**后端逻辑错误**：
- 拆分后，旧任务UNTIL=2026-03-20（拆分前一天）✅
- 新任务DTSTART=2026-03-21，但也继承了UNTIL=2026-03-20 ❌
- **DTSTART > UNTIL**（开始日期 > 结束日期），RRule.js抛出错误

### 根因分析

**错误流程**（backend/src/services/RecurringTaskService.js）：

```javascript
// 第89行：修改旧任务，添加UNTIL=拆分前一天
originalTask.rrule = newOriginalRRule.toString(); // 包含UNTIL=2026-03-20
originalTask.rruleUntil = endDateForOriginal;
await originalTask.save();

// 第104行：创建新任务RRULE
rrule: this._updateRRuleStartDate(originalTask.rrule, splitDate),
// ❌ 传入的 originalTask.rrule 已包含 UNTIL=2026-03-20

// 第105行：新任务继承rruleUntil
rruleUntil: originalTask.rruleUntil, // ❌ 继承了 2026-03-20

// _updateRRuleStartDate 方法（第328-334行）
const rrule = rrulestr(rruleString); // 解析包含UNTIL的RRULE
const options = rrule.options;       // options.until = 2026-03-20
const newRRule = new RRule({
  ...options,                        // 包含 until: 2026-03-20
  dtstart: new Date(newStartDate + 'T00:00:00Z') // dtstart: 2026-03-21
});
// ❌ RRule.js检测到 dtstart > until，抛出错误
```

**核心问题**：
1. **违反时间区间拆分原则**：新任务RRULE基于已修改的旧RRULE创建（包含UNTIL）
2. **错误的实现逻辑**：第104行使用了已修改的`originalTask.rrule`（第92行已添加UNTIL）
3. **导致的后果**：新任务继承了旧任务的UNTIL，造成DTSTART > UNTIL错误

**用户反馈（关键）**：
> "就任务与新任务的RRule正确的方式不是 继承，而是 拆分时间区间；第一步：修改旧规则结束时间；第二步：创建新规则；这两个规则时相关独立的；"

### 修复方案

**方案选择**：**时间区间拆分，不是继承**

正确的时间区间拆分逻辑：
- **第一步**：修改旧规则结束时间（添加UNTIL=拆分前一天）
- **第二步**：基于原始RRULE创建新规则（不含UNTIL）
- **关键**：两个规则应该是独立的时间区间

**修复内容**：

#### 修改1：modifyFuture方法（第74行，新增）

**修改前**：
```javascript
if (!originalTask.isRecurring || !originalTask.rrule) {
  throw new ValidationError('该任务不是重复任务，无法拆分规则');
}

// 计算拆分前一天
```

**修改后**：
```javascript
if (!originalTask.isRecurring || !originalTask.rrule) {
  throw new ValidationError('该任务不是重复任务，无法拆分规则');
}

// ⭐ 保存原始RRULE（在修改旧任务之前），用于创建新任务
const originalRRuleString = originalTask.rrule;

// 计算拆分前一天
```

#### 修改2：modifyFuture方法（第107行）

**修改前**：
```javascript
rrule: this._updateRRuleStartDate(originalTask.rrule, splitDate),
// ❌ 使用已修改的RRULE（包含UNTIL=2026-03-20）
```

**修改后**：
```javascript
rrule: this._updateRRuleStartDate(originalRRuleString, splitDate), // ⭐ 使用保存的原始RRULE，不是修改后的
// ✅ 使用原始RRULE（不含UNTIL），实现时间区间拆分
```

#### 修改3：_updateRRuleStartDate方法（第335行）

**修改前**：
```javascript
const newRRule = new RRule({
  ...options,
  dtstart: new Date(newStartDate + 'T00:00:00Z')
});
```

**修改后**：
```javascript
// ⭐ 创建新RRULE：更新开始日期，移除UNTIL参数（新任务应该永久重复）
const newRRule = new RRule({
  ...options,
  dtstart: new Date(newStartDate + 'T00:00:00Z'),
  until: null // ⭐ 移除UNTIL参数，新任务永久重复
});
```

#### 修改4：modifyFuture方法（第108行）

**修改前**：
```javascript
rruleUntil: originalTask.rruleUntil, // 保留原结束日期（如果有）
```

**修改后**：
```javascript
rruleUntil: null, // ⭐ 新任务永久重复，不继承原UNTIL
```
