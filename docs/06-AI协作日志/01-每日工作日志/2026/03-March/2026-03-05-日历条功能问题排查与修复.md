**拖拽功能可能"未生效"的原因分析**:

##### 可能原因A: 测试环境问题（最可能）
- **H5浏览器测试**: 拖拽基于 `touchstart` 事件触发
- 如果在PC浏览器上用鼠标点击，**不会触发touch事件**
- **解决方法**:
  1. 在Chrome DevTools中开启设备模拟（F12 → Toggle device toolbar）
  2. 或在真实手机/平板上测试
  3. 或使用HBuilderX的内置浏览器预览

##### 可能原因B: 长按时间不足
- 拖拽需要在任务卡片上**按住0.5秒**才会触发
- 如果快速点击或短按，只会触发 `task-click` 事件
- **验证方法**: 长按任务卡片至少500ms，应感受到震动反馈

##### 可能原因C: 任务数据缺失象限字段
- 拖拽依赖任务的 `isUrgent` 和 `isImportant` 字段来判断象限
- 如果测试任务没有这两个字段，拖拽功能会失效
- **验证方法**: 检查 taskStore.tasks 中的任务是否包含这两个布尔字段

#### 问题3: 手势滑动功能（✅ 已完整实现，非Bug）

**用户误解**: 认为手势滑动未实现

**实际情况**: 手势滑动功能已完整实现

**完整事件链**（已全部到位）:

1. **CalendarBar 组件捕获手势**（CalendarBar.vue:186-236）:
   ```javascript
   function onTouchStart(e) {
     touchStartX = e.touches[0].clientX;
     touchStartY = e.touches[0].clientY;
     touchMoved = false;
     touchDir = '';
   }

   function onTouchMove(e) {
     const dx = e.touches[0].clientX - touchStartX;
     const dy = e.touches[0].clientY - touchStartY;
     const adx = Math.abs(dx);
     const ady = Math.abs(dy);

     if (adx < 12 && ady < 12) return; // 阈值12px

     touchMoved = true;
     touchDir = adx > ady * 1.2 ? 'h' : (ady > adx * 1.2 ? 'v' : '');
   }

   function onTouchEnd(e) {
     const dx = e.changedTouches[0].clientX - touchStartX;
     const dy = e.changedTouches[0].clientY - touchStartY;

     if (touchDir === 'h' && Math.abs(dx) > 40) {
       // 水平滑动: 切换周/月
       if (dx < 0) emit('swipe-left');
       else emit('swipe-right');
     } else if (touchDir === 'v') {
       if (mode === 'week' && dy > 50) emit('expand');
       else if (mode === 'month' && dy < -50) emit('collapse');
     }
   }
   ```

2. **index.vue 处理手势事件**（index.vue:34-37）:
   ```vue
   <calendar-bar
     @swipe-left="handleCalendarSwipeLeft"   <!-- ✅ 左滑 → 下一周/月 -->
     @swipe-right="handleCalendarSwipeRight" <!-- ✅ 右滑 → 上一周/月 -->
     @expand="calendarComposable.expandToMonth"   <!-- ✅ 下拉 → 展开月视图 -->
     @collapse="calendarComposable.collapseToWeek" <!-- ✅ 上滑 → 折叠周视图 -->
   />
   ```

3. **handleCalendarSwipeLeft/Right 实现**（index.vue:306-320）:
   ```javascript
   function handleCalendarSwipeLeft() {
     if (calendarComposable.calendarMode.value === 'week') {
       calendarComposable.nextWeek();
     } else {
       calendarComposable.nextMonth();
     }
   }

   function handleCalendarSwipeRight() {
     if (calendarComposable.calendarMode.value === 'week') {
       calendarComposable.prevWeek();
     } else {
       calendarComposable.prevMonth();
     }
   }
   ```

4. **useCalendar Composable 更新日历状态**:
   - `prevWeek()` / `nextWeek()` - 切换周
   - `prevMonth()` / `nextMonth()` - 切换月
   - `expandToMonth()` / `collapseToWeek()` - 展开/折叠

**手势滑动可能"未生效"的原因分析**:

##### 可能原因A: 滑动距离不足
- 水平滑动: 需要超过**40px**
- 垂直下拉（展开）: 需要超过**50px**
- 垂直上滑（折叠）: 需要超过**50px**
- **解决方法**: 用力滑动足够的距离

##### 可能原因B: 滑动方向判断失败
- 代码使用1.2倍比例判断方向（防止斜向误判）
- 如果滑动太斜，可能不会被识别为水平或垂直
- **解决方法**: 尽量沿水平或垂直方向滑动

##### 可能原因C: 测试环境问题（同拖拽）
- 同样依赖 `touchstart/touchmove/touchend` 事件
- PC鼠标点击不会触发
- **解决方法**: 开启设备模拟或在真机上测试

const currentMonthLabel = computed(() => {
  if (calendarMode.value === 'month' && currentMonthFirst.value) {
    const d = currentMonthFirst.value;
    return `${d.getFullYear()}年${d.getMonth() + 1}月`;
  }
  if (!currentWeekStart.value) return '';
  // 取周中间日(周四)所在月
  const d = new Date(currentWeekStart.value);
  d.setDate(d.getDate() + 3);
  return `${d.getFullYear()}年${d.getMonth() + 1}月`;
});

### 问题排查方法论

1. **全面代码审查优于片面猜测**:

2. **事件链追踪法**:

   - 逐层检查事件传递（TaskCard → TaskQuadrantView → index.vue → Composable）
   - 确认每一环是否都到位

3. **区分真实Bug和测试环境问题**:
   - 真实Bug: 代码逻辑错误或缺失（如monthLabel未传递）
   - 测试环境问题: 功能完整但测试方式不当（如PC鼠标测试touch事件）

1. **唯一的真实Bug**: monthLabel prop未传递
2. **两个误报**: 拖拽和手势功能已完整实现
3. **根因**: 用户可能在PC上用鼠标测试基于touch的功能
