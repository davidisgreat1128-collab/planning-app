## 📝 技术决策记录

### 为什么只修改数组顺序和CSS类名？

**问题**：是否需要修改象限key（q1、q2、q3、q4）的定义？

**方案A**（❌ 不推荐）：修改象限key的含义
```javascript
// 将Q2和Q3的key互换
{ key: 'q2', name: '紧急不重要', ... }  // 原Q3
{ key: 'q3', name: '重要不紧急', ... }  // 原Q2
```

**问题**：
- 破坏数据库一致性（已有任务的isUrgent/isImportant会指向错误象限）
- 需要数据迁移
- 影响范围巨大

**方案B**（✅ 推荐，已采用）：只调整UI显示顺序
```javascript
// 保持象限key的含义不变，只调整数组顺序
const quadrants = [
  { key: 'q1', ... },
  { key: 'q3', ... },  // 移到第2位，posClass改为qp-top-right
  { key: 'q2', ... },  // 移到第3位，posClass改为qp-bot-left
  { key: 'q4', ... }
];
```

**优势**：
- 数据库逻辑不变
- 不需要数据迁移
- 影响范围小，只修改UI显示
- 向后兼容

**选择方案B的理由**：
1. **数据一致性**：象限key（q1、q2、q3、q4）的语义不变
2. **最小化影响**：只修改UI显示，不影响业务逻辑
3. **易于回滚**：如果需要恢复，只需改回数组顺序

- QuadrantPicker.vue 中有 quadrants 数组

- task-edit.vue 中有 quadrants 数组
