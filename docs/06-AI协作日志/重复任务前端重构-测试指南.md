## ✅ 测试用例

### 测试用例1: 重复任务完成/取消完成

**功能**: `toggleTaskDone(task)`
**测试场景**: 点击重复任务的完成按钮

**步骤**:
1. 打开日历页面（"做计划"）
2. 选择 2026-03-15（或其他日期）
3. 找到测试重复任务"每日晨跑"
4. 点击任务卡片的完成图标（勾选框）

**预期结果**:
- ✅ 任务状态切换为"已完成"（视觉上应该有变化）
- ✅ 控制台输出: `[index.vue] 重复任务已标记完成: 每日晨跑`
- ✅ 后端创建了 `completion_record`（可在数据库查看 `task_completion_records` 表）
- ✅ 再次点击，状态切换为"待办"
- ✅ 控制台输出: `[index.vue] 重复任务状态已切换: 每日晨跑 → pending`

**验证后端数据**:
```sql
SELECT * FROM task_completion_records WHERE task_id = <taskId> AND completion_date = '2026-03-15';
```

### 测试用例2: 重复任务拖拽删除 - 选项1（仅删除当天）

**功能**: `handleDeleteTaskConfirm(option = 1)`
**测试场景**: 拖拽重复任务到删除区域，选择"仅删除当天任务"

**步骤**:
1. 打开日历页面
2. 选择某个日期（如 2026-03-16）
3. 长按"每日晨跑"任务，开始拖拽
4. 拖拽到屏幕底部删除区域（会出现红色背景）
5. 弹出对话框，选择 **"仅删除当天任务"**

**预期结果**:
- ✅ 控制台输出: `[index.vue] 重复任务-仅删除当天: <taskId> 2026-03-16`
- ✅ 创建了一条 `status='skipped'` 的 `completion_record`
- ✅ 当前日期（2026-03-16）不再显示该任务
- ✅ 其他日期（如2026-03-17）仍然显示该任务
- ✅ 任务定义未被删除（数据库 `tasks` 表中仍存在）

**验证后端数据**:
```sql
-- 应该有 skipped 记录
SELECT * FROM task_completion_records WHERE task_id = <taskId> AND completion_date = '2026-03-16';
-- 状态应该是 'skipped'

-- 任务定义仍然存在
SELECT * FROM tasks WHERE id = <taskId> AND deleted_at IS NULL;
```

## 🐛 已知问题

### 问题1: 后端级联删除未确认

**描述**: 需要确认后端 `DELETE /tasks/:id` 是否会级联删除 `task_completion_records`。

**验证方法**:
```javascript
// 查看 backend/src/models/CompletionRecord.js
// 应该有类似配置:
CompletionRecord.belongsTo(Task, {
  foreignKey: 'taskId',
  onDelete: 'CASCADE'  // 或 'SET NULL'
});
```

**影响**: 如果没有级联删除，手动删除重复任务后，`completion_records` 会变成孤儿数据。
