# 腾讯云DNS设置

你这个问题本质是：**把域名指向你的服务器 IP（DNS 解析）**，在腾讯云上叫“解析记录配置”。

我一步一步带你做 👇

------

## 🧠 一、你要做的事情是什么？

你需要在 Tencent Cloud 的 **域名解析控制台**里添加一条记录：

👉 把你的域名（例如：`txjjzyzqbx.cn`）指向你的服务器公网 IP（例如：`154.8.xxx.xxx`）

------

## ✅ 二、进入域名解析控制台

1. 登录腾讯云控制台
2. 找到：

👉 **云产品 → 域名与网站 → 域名解析**

或直接搜索：

👉 “DNS解析”

------

## ✅ 三、添加解析记录（核心步骤）

点击你的域名（例如：`txjjzyzqbx.cn`）

然后点击：

👉 **添加记录**

填写如下：

| 参数     | 填写内容                              |
| -------- | ------------------------------------- |
| 记录类型 | A                                     |
| 主机记录 | @（根域名）                           |
| 记录值   | 你的服务器公网 IP（如 154.8.xxx.xxx） |
| TTL      | 默认即可                              |

------

## 📌 如果你还想支持 www

再加一条：

| 参数     | 填写内容  |
| -------- | --------- |
| 记录类型 | A         |
| 主机记录 | www       |
| 记录值   | 同一个 IP |

------

## 🧠 四、解析完成后会发生什么？

当用户访问：

```
http://txjjzyzqbx.cn
```

DNS 会把它解析为：

```
你的服务器 IP → 154.8.xxx.xxx
```

👉 浏览器就会访问你的服务器

------

## ⏱️ 五、解析生效时间

一般：

- 几秒～几分钟
- 最长可能 10~30 分钟

------

## ✅ 六、如何验证是否成功

在你本地电脑执行：

```
ping txjjzyzqbx.cn
```

如果返回你的服务器 IP，说明解析成功 ✅

或者：

```
nslookup txjjzyzqbx.cn
```

------

## 🎯 总结一句话

> 在腾讯云 DNS 控制台添加一条 A 记录，把域名指向你的服务器公网 IP，就完成了解析。
