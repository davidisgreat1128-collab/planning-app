## 3. 服务器环境配置

### 3.1 防火墙配置

```bash
# Ubuntu/Debian
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 22/tcp
ufw enable

# CentOS/RHEL
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=443/tcp
firewall-cmd --permanent --add-port=22/tcp
firewall-cmd --reload
```

**⚠️ 重要**: 不要开放3000、3306、6379端口（内网访问）

## 9. 故障排查

### 9.1 DNS解析失败

**现象**: `nslookup txjjzyzqbx.cn` 无结果

**解决**:
1. 检查腾讯云DNS配置是否正确
2. 等待5-10分钟让DNS生效
3. 清除本地DNS缓存: `ipconfig /flushdns` (Windows) 或 `systemd-resolve --flush-caches` (Linux)

### 9.2 SSL证书申请失败

**现象**: `setup-ssl.sh` 报错

**检查项**:
- [ ] DNS是否正确解析到服务器IP？
- [ ] 防火墙是否开放80端口？
- [ ] Nginx容器是否已停止？（申请时不能占用80端口）
- [ ] 域名是否已备案？（中国大陆服务器需要）

**解决**:
```bash
# 查看certbot详细日志
certbot certificates
tail -n 50 /var/log/letsencrypt/letsencrypt.log
```

### 9.3 容器启动失败

**现象**: `docker-compose ps` 显示容器Exited

**诊断**:
```bash
# 查看失败容器日志
docker-compose logs <服务名>

# 例如：
docker-compose logs mysql
docker-compose logs backend
```

**常见原因**:
- MySQL: 数据目录权限问题、内存不足
- Backend: 环境变量配置错误、数据库连接失败
- Nginx: 配置文件语法错误、SSL证书路径错误

### 9.4 数据库连接失败

**现象**: Backend日志显示 `ECONNREFUSED mysql:3306`

**解决**:
```bash
# 检查MySQL是否启动
docker-compose exec mysql mysqladmin ping -uroot -p

# 检查.env中的数据库配置
cat .env | grep MYSQL

# 重启MySQL
docker-compose restart mysql
```

### 9.5 HTTPS访问失败

**现象**: `curl https://txjjzyzqbx.cn` 报错

**检查项**:
- [ ] SSL证书是否申请成功？
- [ ] Nginx配置是否切换到HTTPS模式？
- [ ] 防火墙是否开放443端口？

**解决**:
```bash
# 检查证书文件是否存在
ls -lh /etc/letsencrypt/live/txjjzyzqbx.cn/

# 检查Nginx配置
docker-compose exec nginx nginx -t

# 查看Nginx日志
docker-compose logs nginx
```
