## 🎯 根据场景选择文档

### 场景1: 首次部署

1. 阅读 [部署方案摘要.md](./部署方案摘要.md)（5分钟）
2. 准备服务器环境
3. 按照 [生产部署完整指南.md](./生产部署完整指南.md) 执行部署（60分钟）

### 场景2: 遇到部署问题

1. 查看 [生产部署完整指南.md](./生产部署完整指南.md) 第9节"故障排查"
2. 如果问题未解决，查看部署脚本日志：
   ```bash
   tail -f logs/health.log
   docker-compose logs -f
   ```

### 场景3: 日常运维

1. 参考 [运维手册.md](./运维手册.md) 第1节"日常运维"
2. 每日巡检（5分钟）
3. 每周维护（30分钟）
4. 每月维护（1小时）

### 场景4: 数据备份与恢复

1. 参考 [运维手册.md](./运维手册.md) 第3节"备份与恢复"
2. 自动备份：已配置定时任务（每日凌晨2点）
3. 手动备份：`bash scripts/backup-mysql.sh`
4. 数据恢复：`bash scripts/restore-mysql.sh <备份文件>`

### 场景5: SSL证书续期

1. 自动续期：已配置定时任务（每月1号凌晨3点）
2. 手动续期：`bash scripts/renew-ssl.sh`
3. 检查证书有效期：`certbot certificates`

## 📁 配置文件位置

### Docker相关

- `docker-compose.yml` - Docker Compose编排文件
- `.env.example` - 环境变量模板（需复制为.env并填写）
- `backend/Dockerfile` - 后端镜像构建文件
- `backend/.dockerignore` - Docker构建排除文件

### Nginx配置

- `nginx/nginx.conf` - Nginx主配置
- `nginx/conf.d/planning-app-http.conf` - HTTP配置
- `nginx/conf.d/planning-app-https.conf` - HTTPS配置

### 部署脚本

- `scripts/generate-secrets.sh` - 生成安全密钥
- `scripts/deploy.sh` - 一键部署
- `scripts/setup-ssl.sh` - SSL证书申请
- `scripts/renew-ssl.sh` - SSL证书续期
- `scripts/backup-mysql.sh` - MySQL备份
- `scripts/restore-mysql.sh` - MySQL恢复
- `scripts/health-check.sh` - 健康检查

### 数据库配置

- `database/init.sql` - MySQL初始化脚本
