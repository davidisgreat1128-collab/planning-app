### 部署步骤

#### 步骤1: 上传项目到服务器

```bash
# 在服务器上执行
cd /opt
git clone git@github.com:davidisgreat1128-collab/planning-app.git
cd planning-app
```

#### 步骤2: 生成安全密钥

```bash
bash scripts/generate-secrets.sh
```

**输出**: 自动生成 `.env` 文件，包含所有密钥

#### 步骤3: 检查DNS解析

```bash
nslookup txjjzyzqbx.cn
# 应返回: 154.8.183.203
```

#### 步骤4: 执行部署

```bash
bash scripts/deploy.sh
```

**预计时间**: 15-20分钟

**输出**:
```
[INFO] ✅ 部署成功！
服务访问地址:
  - API端点: http://154.8.183.203/api/v1/
  - 健康检查: http://154.8.183.203/health
```

#### 步骤5: 申请SSL证书

```bash
bash scripts/setup-ssl.sh
```

**预计时间**: 3-5分钟

**输出**:
```
[INFO] ✅ SSL证书配置成功！
访问地址:
  - HTTPS: https://txjjzyzqbx.cn/health
  - HTTP自动跳转: http://txjjzyzqbx.cn → https://txjjzyzqbx.cn
```

#### 步骤6: 配置定时任务

```bash
crontab -e
```

添加以下内容:

```bash
# 每日MySQL备份（凌晨2点）
0 2 * * * /opt/planning-app/scripts/backup-mysql.sh >> /opt/planning-app/logs/backup.log 2>&1

# SSL证书自动续期（每月1号凌晨3点）
0 3 1 * * /opt/planning-app/scripts/renew-ssl.sh >> /opt/planning-app/logs/ssl-renew.log 2>&1

# 健康检查（每5分钟）
*/5 * * * * /opt/planning-app/scripts/health-check.sh >> /opt/planning-app/logs/health.log 2>&1
```

#### 步骤7: 验证部署

```bash

# 2. 测试HTTPS访问
```

## 🔐 安全要点

### 端口暴露策略

| 端口 | 服务 | 外网访问 | 说明 |
|------|------|---------|------|
| 80 | HTTP | ✅ 允许 | 仅用于跳转HTTPS和SSL证书验证 |
| 443 | HTTPS | ✅ 允许 | 主服务端口 |
| 3000 | Backend | ❌ 禁止 | 仅内网访问（通过Nginx代理） |
| 3306 | MySQL | ❌ 禁止 | 仅内网访问 |
| 6379 | Redis | ❌ 禁止 | 仅内网访问 |

### 密钥管理

**⚠️ 重要**: `.env` 文件包含所有密钥，必须：

- ✅ 妥善保管（保存到密码管理器）
- ✅ 禁止提交到Git（已在.gitignore）
- ✅ 定期轮换（建议每6个月）

## 📊 技术架构

```
用户（UniApp / 浏览器）
        ↓
https://txjjzyzqbx.cn (DNS解析)
        ↓
154.8.183.203:443 (腾讯云服务器)
        ↓
Nginx (SSL证书 + 反向代理)
  ├─ HTTP(80) → HTTPS(443) 跳转
  └─ HTTPS(443) → Backend(3000)
        ↓
Node.js Backend (Express)
  ├─ MySQL(3306) ← 内网访问
  └─ Redis(6379) ← 内网访问
```
